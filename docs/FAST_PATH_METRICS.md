# Fast Path Metrics

O Fast Path deve ser otimizado por medição, não por suposição.

As métricas atuais acompanham:

- eventos avaliados;
- decisões aceites/rejeitadas;
- eventos stale;
- rejeições de risco;
- tentativas e sucessos de execução;
- latência média de avaliação;
- latência média de execução.

Estas métricas são instrumentação. Não alteram risco, exposição, capital ou autorização REAL.
